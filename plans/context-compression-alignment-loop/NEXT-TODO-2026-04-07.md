1. 先把 Formax 现有的 query-time 减压步骤收敛到统一策略栈

### `CCA-140` middle-layer strategy stack scaffolding

目标：
- 不引入新的重型持久化模型，先把现有 query-time 减压步骤收敛成统一策略栈承载
- 让 `microcompact` / `collapse` / `prune` 不再只是 send-path 里的若干步骤，而是有统一的 strategy input / output / facts 结构

验收：
1. send-path 内存在统一的 middle-layer strategy execution order
2. 策略结果至少能统一表达：
   - `applied/skipped`
   - `estimatedTokensSaved`
   - per-strategy facts / reason
3. `/context` 优先复用 runtime strategy facts，而不是重复推导
4. 第一刀不改变已有 `microcompact` / `collapse` / `prune` 的对外语义

### `CCA-141` tool-result budget replacement v1

目标：
- 把“工具结果预算”从 `microcompact` 的间接副作用，提升成一条独立中间层策略

验收：
1. request payload 会对 tool-result group 单独计预算
2. 超预算 tool result 先经过 replacement/summarization，再交给更重的层
3. `/context` assembled ledger 与 strategy facts 能单独显示这层收益
4. 这条策略不改 persisted history

### `CCA-142` cache-aware microcompact v3

目标：
- 在 `CCA-140` 的统一承载下，把 `microcompact` 从 family-aware/threshold-aware 推进到 cache-aware / time-aware 路径

验收：
1. `microcompact` 不再只按工具族和体量判断
2. 至少有一条 cache-aware 或 time-aware 路径进入运行时
3. diagnostics 能解释命中的 cache-aware policy/facts
4. 不与 `CCA-141` 的 tool-result budget replacement 语义冲突

当前状态：已完成
